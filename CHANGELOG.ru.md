# История изменений

[English](CHANGELOG.md)

## [0.1.1] — 2026-10-13

### Исправлено
- Выбранная папка создаётся **сразу при выборе**, поэтому окно «Сохранить как» (если в Chrome включено «Всегда указывать место для скачивания») открывается прямо в ней, а не в «Загрузках».
- Если Chrome сохранил файл в другое место, это больше не считается успехом: папка сверяется точно с `Загрузки/<папка>`, а уведомление подсказывает частые причины.
- Две загрузки, начатые одновременно (например, вложения Gmail), больше не теряют запись о маршруте.

### Добавлено
- **Настройки → Скопировать диагностику**: последние 20 загрузок (режим, тип файла, нужная и фактическая папка; без имён файлов и полных путей) для отчёта об ошибке.
- В строке статуса сначала папка: «В Documents/: файл.docx».

## [0.1.0] — 2026-10-12

### Добавлено
- Попап с шестью режимами: **По умолчанию Chrome**, **Документы**, **Изображения**, **Видео**, **Архивы**, **Своя папка** — папка загрузки меняется в два клика.
- Подпапки внутри «Загрузок» создаются автоматически при первой загрузке.
- **Авторазбор по типу файла** (pdf → Документы, jpg → Изображения, mp4 → Видео, zip → Архивы, неизвестное → по умолчанию).
- **Только для следующей загрузки** — разовый режим, затем возврат к умолчанию.
- Своя папка: проверка на лету, «Исправить автоматически», недавние папки.
- Редактируемые пресеты (имя, папка, иконка).
- Горячие клавиши Alt+Shift+1…4 (отключаются), значок на панели (DOC, IMG, VID, ZIP, DIR, AUTO).
- Уведомления об ошибках с «Повторить» / «Открыть папку»; файл не теряется — Chrome оставит его в «Загрузках».
- Английский, русский, китайский (упрощённый) и испанский; светлая тема и переключатель тёмной.
- Карточка поддержки (ETH) и ссылки в настройках.
