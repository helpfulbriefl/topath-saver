# ToPath Saver

## Краткое описание
Папки для загрузок в два клика. Авторазбор файлов, сохранение видимых вложений Gmail и горячие клавиши.

## Подробное описание
Поддерживайте порядок в загрузках внутри папки «Загрузки» Chrome. Выберите «Документы», «Изображения», «Видео», «Архивы» или собственную относительную подпапку. Выбор папки сам по себе не запускает загрузку.

- Автоматически раскладывайте новые загрузки по типу файлов.
- Сохраняйте видимые вложения открытого письма Gmail отдельными файлами через «Скачать все из Gmail» (до 50 за раз).
- Используйте разовый режим для одной загрузки или одной пачки Gmail, а затем возвращайтесь к предыдущей папке.
- Переключайтесь горячими клавишами. Настраивайте язык, светлую/тёмную тему и четыре стиля иконок.

Настройки и диагностика остаются локально на устройстве. Нет аналитики, отслеживания или запросов к серверам разработчика. По вашему нажатию Chrome скачивает файлы Gmail с серверов Google.

Требуется Chrome 116 или новее. Папки должны находиться внутри «Загрузок». Расширение не перемещает уже скачанные файлы. Поиск Gmail зависит от видимых вложений в открытом письме; скрытые или свёрнутые вложения могут не быть найдены. На маршрутизацию загрузок могут влиять другие расширения или настройки браузера.
