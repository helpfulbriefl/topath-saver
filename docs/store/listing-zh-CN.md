# ToPath Saver

## 简介
两次点击选择下载文件夹。按类型自动分类文件，保存 Gmail 中可见的附件，并使用键盘快捷键。

## 详细说明
让下载内容在 Chrome 的“下载”文件夹中保持有序。可选择“文档”“图片”“视频”“压缩包”或自定义相对子文件夹。选择文件夹本身不会启动下载。

- 按文件类型自动分类新的下载文件。
- 通过“从 Gmail 下载全部”，将当前打开的 Gmail 邮件中可见的附件保存为单独文件（每批最多 50 个）。
- 对一次下载或一批 Gmail 附件使用单次模式，随后返回先前的文件夹。
- 使用键盘快捷键切换。可自定义语言、浅色/深色主题和四种图标样式。

设置和诊断信息保留在本机。没有分析、跟踪或对开发者服务器的请求。您点击操作后，Chrome 会从 Google 下载 Gmail 文件。

需要 Chrome 116 或更高版本。文件夹必须位于“下载”目录中。扩展不会移动已下载的文件。Gmail 发现功能依赖打开邮件中可见的附件；隐藏或折叠的附件可能无法被找到。其他扩展或浏览器设置可能影响下载路由。
